Я створив схожу програму на двох мовах програмування: Python і C#.
Зробив я це, тому що хотів спробувати порівняти, наскільки принципи ООП відрізняються у настільки різних мовах.
Як виявилося, головною різницею була просто мовна реалізація, наприклад:
- У Python для роботи з атрибутами завжди потрібно потрібно писати "self.атрибут"; у C# еквівалент "this.атрибут" в багатьох випадках можна взагалі не писати.
- Усі методи класу у Python також потребують аргумент self; у C# нічого такого робити не потрібно.
- Будь-який атрибут класу може бути будь-якого типу (як і будь-які інші змінні); у C# все чітко.
І, звичайно, мовленнєві різниці: print та Console.WriteLine, синтаксис циклів for та while, структур if-elif-else та if-else, try-except та try-catch, match-case та switch-case тощо.
